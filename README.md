# SQL Database Projects

This repository contains two beginner-friendly SQL database management projects developed using **MySQL**.
Each project includes:

* Database creation
* Table creation with relationships
* Sample data insertion
* SQL queries
* Aggregate functions
* Joins and subqueries
* ER (Entity Relationship) diagrams

---

# 📚 Project 1: Bookstore Database

A complete bookstore management database system designed using MySQL.

## Features

* Authors management
* Genres management
* Customer details
* Books inventory
* Orders and Order Details
* Joins and subqueries
* Aggregate SQL functions

## Tables Used

1. Authors
2. Genres
3. Customers
4. Books
5. Orders
6. Order_Details

## Concepts Covered

* Primary Keys
* Foreign Keys
* One-to-Many Relationships
* Aggregate Functions
* Nested Queries
* Joins

## Sample Queries

* Books with price greater than 300
* Books with low stock
* Genre-wise stock calculation
* Books with author names
* Customers who placed orders

## Technologies Used

* MySQL
* SQL
* ER Modeling

# 🛒 Project 2: Online Shopping Database

A simple online shopping database system using MySQL.

## Features

* Customer management
* Product inventory
* Order processing
* Order item tracking
* Aggregate queries
* Joins and subqueries

## Tables Used

1. Customers
2. Products
3. Orders
4. Order_Items

## Concepts Covered

* Database normalization
* Primary & Foreign Keys
* Relationships
* Aggregate Functions
* SQL Queries
* Joins

## Sample Queries

* Products with high price
* Products with low stock
* Category-wise stock analysis
* Order details with customer names
* Products costlier than average price

## Technologies Used

* MySQL
* SQL
* ER Modeling
